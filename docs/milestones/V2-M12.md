# V2-M12 — Annotation tools II: text, stamps, mover

**Tag at the end:** `v1.12.0`. **Model:** mid-tier, medium effort; plan step with the strongest model (PDF storage). **Prerequisite:** M7, M11 done.

**Requirements:** R-20a…p, R-61, D-21, D-27.

**Requirement IDs:** SAV-018, ORG-046, ANN-031, ANN-032, ANN-033, ANN-034, ANN-035, ANN-036, ANN-037, ANN-038, ANN-039, ANN-040, ANN-041, ANN-042, ANN-043, ANN-044, ANN-045.

Goal: text, music stamps and a mover tool exist next to pen, highlighter and eraser; they are stored as standard PDF annotations that other viewers display and the app can read back; all annotations are visible (read-only) in organization mode.

## Steps (the owner commits after each)

### S1 — Storage design and spike (strong model, plan step)

1. Decide and record in `docs/decisions.md` how text and stamps are stored: standard PDF annotations (`/FreeText` for text, `/Stamp` or an appearance-stream-based annotation for symbols) with **appearance streams written by the app** (as the V1 ink writer does for `/Ink`), plus the app's own data (symbol id, text, size, color) in the existing metadata so the app can edit them. Other viewers show the appearance stream.
2. Spike: write one text and one stamp with pdf-lib into a corpus PDF; open the result in pdf.js (the app's renderer), and check it with `qpdf --check`; list in the report how it looks in at least two other viewers if the owner provides them (Preview, Acrobat, a mobile viewer).
3. Existing foreign annotations stay preserved (SAV-013). Reading existing `/FreeText` and stamp annotations of other apps is **not** required (display only).

### S2 — Text tool (R-20j, m, n)

Default size and smaller/larger buttons (tunables). A click places a writing cursor that also serves as the preview; multiline input; confirmed by tapping elsewhere; editable by clicking the text with the text tool active; an empty text creates nothing. The text uses the shared pen color (R-20i). Text does not wrap automatically (explicit newlines only) in v2.

### S3 — Stamps (R-20b, c, p, D-21)

1. Dependency: the **Bravura** music font (SIL OFL), recorded in `docs/decisions.md` (M0); converted to SVG glyph paths at build time or shipped as a subset font; included in `THIRD_PARTY_NOTICES.txt`; **no CDN** (R-8d).
2. Symbol source: a flat list in tunables: dynamics, accidentals, fingering, strings/bowing, winds/breaths, articulation, rehearsal/navigation (letters, numbers, segno, coda, D.C., D.S., fine), warnings (glasses, check, arrows, circle, asterisk). The initial 8 (`T:stamps.initial`) are chosen here with the owner's review of the proposal in the report.
3. Stamp tool: draws on each click; size via smaller/larger buttons like thickness. Popup: n (default 8, tunables) most recently used stamps in a 3×3 grid; the ninth cell is three dots opening a scrollable submenu with all symbols; free/web always starts with the tunables set (no persistence). The tool button shows the selected symbol; the cursor shows a stamp preview. Group names need no translation.

### S4 — Mover and eraser (R-20g/h)

The **mover** moves any annotation in x/y (strokes, text, stamps); it selects like the eraser; no resize after drawing. The eraser also removes text and stamps. All three tools are undoable (M7).

### S5 — Annotations in organization mode (R-61, D-27)

Annotations of annotation mode (ink, text, stamps) are drawn read-only on the organization-mode pages (an overlay layer in the tile renderer; no per-pointer-event work). No drawing in organization mode; unplayed systems and pages without systems stay unannotatable (LIM-016 stays). Assumed: always shown, no setting.

## Tests

- Unit: placement/size math, recent-stamps list (most recent first, capacity n), text editing state machine, metadata round trip of text/stamps (seeded property test), mover hit testing.
- E2E: draw text, a stamp, move both, erase one, save a copy, reload, `qpdf --check`, pdf-lib reads the annotations, pdf.js renders them; organization mode shows the same annotations; free/web: stamps popup starts from tunables.
- Manual (owner): open a saved copy in two other PDF viewers.

## Do not

- Do not add rotation, resize, fonts selection or rich text.
- Do not import annotations from other apps for editing.
- Do not make network requests for fonts.
- Do not add drawing in organization mode.

- [ ] Annotations visible in organization mode.
