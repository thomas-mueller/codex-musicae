# V2-M5 — Settings mode, languages, tooltips, icons

**Tag at the end:** `v1.5.0`. **Model:** mid-tier, medium effort. **Prerequisite:** M3 done.

**Requirements:** R-12a/b, R-6d, R-47b/g/i (infrastructure), R-46a…d, R-5a…d, R-UX1.

Goal: the app gets a settings mode that later milestones fill, a working language layer with seven languages (English and German complete, others filled in M16), tooltips that never leave the screen, and one icon registry.

## Steps (the owner commits after each)

### S1 — Settings mode (R-12a/b)

1. A new mode "settings" reachable by the rightmost top-bar button (three lines icon, `T:icons.settings`). It opens a full-area view with groups **General, Display, Slide mode, Files** (group names are translation keys). Groups start with the settings that already exist in V1 (persisted tool colors and widths remain in tool popups, not here).
2. A `SettingsRegistry` (`state/`): each setting declares `id`, group, type (boolean/choice/number-in-seconds), default (from `tunables`), the feature switch it depends on, and whether it persists (through the persistence switch of M3; in free/web it lives only in the session). Later milestones register their settings here; no setting is hard-coded in the view.
3. Settings are abstract and non-technical (R-UX1); no algorithm parameters here.
4. Pedal remapping is **not** part of V2.

### S2 — Reset all settings (R-6d)

One button "Reset all settings" in General, with a confirmation dialog, that resets everything the registry knows plus palette colors, thicknesses, language, highlight mode, marks switch, dead time, suppressed warnings, per-file choices and first-run hints. It never touches file content (marks, annotations). A `ResettablePort`-style hook lets later milestones register their own reset handlers (the registry exposes `registerReset()`).

### S3 — Languages (R-47b/g/i)

1. Translation files `src/assets/i18n/{en,de,es,fr,it,pt-BR,nl}.json` (transloco, as V1). Files other than `en` and `de` start as copies of `en` marked in `docs/i18n-status.md` (completed in M16).
2. Language: follow the system language (`navigator.languages`), changeable in the General group, fallback English. Persisted through the registry (free/web: session only).
3. Test (unit, build time): every key of `en.json` exists in all seven files (fails for missing keys; values copied from English are allowed until M16 via an explicit list in `docs/i18n-status.md`, which M16 must empty). Lint rule I18-001 stays.
4. Pseudo-test for layout: a "long text" run (German strings plus 40 % padding) over all settings and the top bar checks no text is cut off (`scrollWidth <= clientWidth` or wrapped); a helper reused by M16.

### S4 — Tooltips and icons (R-46, R-5)

1. Tooltips (`features/shell/tooltip.directive.ts`): keep triggers (hover 600 ms, touch long press 500 ms); **clamp to the screen** at every edge, allow multiple lines (`T:layout.tooltipMaxWidthPx`, value chosen here and recorded in D-2 list), keep placement below the control (above in the bottom bar).
2. Icons: all names in `T:icons`, built into the sprite by `npm run build:icons`; add a test that every `T:icons` name exists in the sprite and every icon button has a translated accessible label (GEN-010 stays).
3. Write `docs/icons.md` (owner how-to, short): where icons live, how to replace one, which test covers it (R-5a…d). The agent chooses icons for the new buttons (settings, reset) and lists them.

## Tests

- Unit: registry (defaults, persistence switch, reset handlers), language selection (system language, fallback), key-completeness, tooltip clamp math in `core/` (pure function with fixtures for four edges and corners).
- E2E: open settings, change language to German, reload (paid/native-config build keeps it, web build does not), reset restores defaults; tooltip near each screen edge stays inside the viewport on phone and tablet profiles.

## Do not

- Do not add settings that belong to later milestones (they register themselves).
- Do not translate beyond `en` and `de`.
- Do not add pedal remapping or keyboard shortcut settings.
- Do not change V1 tool popups.
