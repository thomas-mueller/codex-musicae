# V2-M16 — First-run hints and translations

**Tag at the end:** `v1.16.0`. **Model:** mid-tier, low effort for S1; **smallest tier** for S2 (translations). **Prerequisite:** M10–M15 done (the workflow the hints describe is frozen).

**Requirements:** R-19m…t (BKL-019), R-47b/g/i, D-3, D-25.

Goal: eight tip bubbles guide a first-time user through the typical workflow once; all texts, and all other texts of the app, exist in seven languages with tests that prove completeness and fit.

## Steps (the owner commits after each)

### S1 — Hints (R-19m…t, D-25)

1. A `HintService` (`state/`) with a declarative list of eight hints, each bound to a **trigger**, an **anchor** (the control or area it explains) and a text key: (1) open a file (a new file without stored systems opens in **organization mode**; one with systems opens in annotation mode, D-25), (2) detection progress, (3) detected systems shown, (4) creating marks of different kinds, (5) change to annotation mode, (6) change the aspect ratio, (7) pen annotation, (8) change to slide mode. **No hints** for the detection tool or the refine tool.
2. Each hint appears once, at the moment its step becomes relevant. Bubbles never block input, disappear on tap or after `T:hints.autoHideMs`, stay inside the screen and never cover the control they explain (placement function in `core/`, fixtures for all edges, shared with tooltips).
3. A checkbox in the General group ("Show hints") turns all hints off; "Reset all settings" turns them back on. Shown-state persists in paid native; in free/web a hint shows at most once per session.
4. The V1 behavior "opens in annotation mode after startup" (FIL-012) changes only for files without stored systems; the affected V1 test is explicitly allowed to change and is listed.

### S2 — Translations (R-47b/g/i)

1. Complete `es`, `fr`, `it`, `pt-BR`, `nl` from `en` (and `de` review): fill all keys, empty the "copied from English" list in `docs/i18n-status.md`. German is mandatory and reviewed by the owner; the other five are marked "machine-assisted, native review pending" in `docs/i18n-status.md` until M19.
2. Tests: key completeness in all seven files (no key missing, none unused), no placeholder left (`{{…}}` parameters equal in all languages), and a **fit test** (the M5 helper) over every screen of the app (top bar, settings, popups, hint bubbles, dialogs) in every language on the phone and tablet profiles: no text cut off.
3. `docs/i18n-status.md` lists the review state per language and the reviewer.

## Tests

- Unit: hint trigger table, once-only logic, suppression by the switch, reset, session-only behavior in free/web, placement fixtures.
- E2E: walk the workflow on a corpus file: each hint appears at its trigger, once; switch off suppresses all; reset shows them again; German run for text fit.
- i18n: tests of S2.2.

## Do not

- Do not add an intro screen or tutorial.
- Do not add hints for further controls.
- Do not change feature behavior to fit a hint.
- Do not claim a native review in `i18n-status.md` that has not happened.

## Acceptance criteria

- [ ] Eight hints with triggers, once only, suppression and reset tests green.
- [ ] Seven complete language files; completeness and fit tests green on both profiles.
- [ ] Requirement statuses updated; lint, unit tests, E2E, build green.

## Owner step

Review the German texts and read the other languages' hints once, commit, then `git tag v1.16.0 && git push --tags`. Send the language files to your native-speaker reviewers (they review during M18/M19).
