### S1 — `generatePlayingOrder`, `isValidJump`, `isValidMarkJunction`

```
arrivals = array(N+1) of 0;  entries = [];  events = [];  position = 0;  truncated = false
loop:
    arrivals[position] += 1
    events.push({ junction: position, len: entries.length })
    jump = first jump in input.jumps with origin == position and pass == arrivals[position]
    if jump exists: position = jump.target; continue
    if position == N: break
    if entries.length >= maxLength: truncated = true; break
    entries.push(position + 1); position += 1

between[k] for k in 0 .. entries.length-2  =  junctions of the events with len == k+1, in event order
stops:  for each stop s that has events:  cut(s) = len of its LAST event
        if any: cut = min(cut(s));  entries = entries[0:cut];  between = between[0 : max(0, cut-1)]
return { entries, between, truncatedByCap: truncated }
```

Notes: the arrival at junction 0 at the very start is event `len 0`; it is never part of `between`. A jump from junction N fires on arrival at N before the order ends. A stop reached before any entry gives an empty order (`O18`).

`isValidJump`: `origin`, `target`, `pass` are integers; `0 <= origin <= N`; `0 <= target <= N`; `origin !== target`; `pass >= 1`. `isValidMarkJunction`: integer and `1 <= j <= N-1`.

### S3 — `slides.ts`

```
referenceWidth = max over systems of padded.width
packSlides:
    H = slideWidth / aspectRatio;  slides = [];  open = null
    for i in 0 .. entries.length-1:
        s = systems[entries[i]-1]
        if open != null and forcedBreakAfter[i-1] is not true:
            prev = systems[entries[i-1]-1]
            adjacent = entries[i] == entries[i-1] + 1 and s.pageIndex == prev.pageIndex
            trial = copy of open.regions
            if adjacent:  last = trial[last]; last.area = union(last.area, s.padded); last.lastSystem = s.index; last.entryEnd = i
            else:         trial.push(region(page s.pageIndex, firstSystem = lastSystem = s.index, area = s.padded, entryStart = entryEnd = i))
            stack = sum of area.height over trial
            if stack <= H + 1e-9: open.regions = trial; continue
        if open != null: slides.push(close(open, i-1))
        open = new slide with entryStart = i and one region for s
    close the last open slide with entryEnd = entries.length-1
close(slide, entryEnd): stack = sum of region heights; enlarged = stack > H + 1e-9
    height = enlarged ? stack : H;  width = enlarged ? height * aspectRatio : slideWidth
slideIndexOfEntry: index of the slide with entryStart <= e <= entryEnd, else -1
```
