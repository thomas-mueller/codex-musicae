# V1-M7 — Application shell

**Tag at the end:** `v0.7.0`. **Model:** mid-tier, medium effort. **Prerequisite:** M6 done. M2 provides `APP_VERSION`.

**Requirements:** GEN-007, GEN-008, GEN-009, GEN-010, FIL-007, UIX-001, UIX-002, UIX-003, UIX-004, UIX-005, UIX-006, UIX-007, UIX-008, UIX-010, UIX-011, UIX-012, UIX-013, UIX-014, UIX-015, UIX-016, UIX-017.

Goal: the complete visual frame of the app in all three modes and both size classes, with every control present, correctly styled, accessible and disabled where it needs a document. No PDF, no tabs, no real functionality: state changes only (mode, tool, popups).

## Core part (do first)

Copy `docs/contracts/core/layout.ts` and `fixtures/layout.cases.ts` into `src/app/core/`, write `layout.spec.ts` from the fixtures (red, `not implemented` only), implement `sizeClassOf` (`width < compactMaxWidthPx || height < compactMaxHeightPx` → compact). Add the export to `core/index.ts`.

## Steps (the owner commits after each)

### S1 — Frame, state, size classes (GEN-007, GEN-008, UIX-001, UIX-003, UIX-008, UIX-016, UIX-017)

1. `UiStore` (`state/`): signals `mode` (`'organization' | 'annotation' | 'presentation'`, default `'annotation'`), `tool` (`null | 'pen' | 'highlighter' | 'eraser'`, default `null`), `popup` (`null | { id: string }`), `viewport` (`{width, height}`), computed `sizeClass` (via `sizeClassOf` with `T:layout`).
2. `applyTunablesToCss()` in the composition root: writes CSS custom properties on `:root` from `tunables` (`--cm-canvas-grey`, `--cm-accent`, `--cm-on-accent`, `--cm-icon`, `--cm-bar-bg`, `--cm-bar-height`, `--cm-touch-target`, `--cm-disabled-opacity`, …). No color or size literal in component CSS; only `var(--cm-…)`.
3. `index.html`: `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`; `html, body` fill the viewport (`height: 100%`, no page scroll, `overflow: hidden`); only the light theme.
4. `AppShell` component: a grid with three rows: top area, canvas area (flex 1), bottom area. A `ResizeObserver` directive on the shell updates `UiStore.viewport`. Bars use `padding` from `env(safe-area-inset-*)`.
5. `CanvasArea`: background `var(--cm-canvas-grey)`, fills the middle row; inside it a placeholder element for the later content. Nothing but grey is visible there (FIL-007).
6. `presentation` mode: shell shows only the canvas area (no bars, no tool strip), full size. Its content is empty for now.

### S2 — Controls, icons, tooltips, popups (GEN-009, GEN-010, FIL-007, UIX-002, UIX-004…007, UIX-010…015)

**Icons.** Bundle a self-hosted subset of Material Symbols Outlined as SVG (choose a package that ships one SVG per icon, or generate a sprite with a script; record the choice in `decisions.md`). A script `scripts/build-icons.mjs` reads `tunables.icons` and produces the assets; a unit test asserts that every name in `tunables.icons` has an SVG. No CDN, no font download at runtime.

**`IconButton`** (`features/shell/`): inputs `icon` (a key of `tunables.icons`), `labelKey` (translation key), `toggled`, `disabled`; output `pressed`. Min size `T:layout.minTouchTargetPx`; icon monochrome `var(--cm-icon)`; toggled = filled `var(--cm-accent)` circle/rounded square with `var(--cm-on-accent)` icon; untoggled = transparent; disabled = opacity `var(--cm-disabled-opacity)`, `tabindex=-1`, `aria-disabled`. Every button has `aria-label` from the translation file (key `a11y.<labelKey>`). Tooltips (`TooltipDirective`): text from `tooltip.<labelKey>`, shown after `T:layout.tooltipHoverDelayMs` pointer hover, or after `T:layout.longPressMs` long press (touch), hidden on leave/release.

**Popup primitives:** `PopupHost` renders at most one popup or sheet at a time from `UiStore.popup`. A popup closes on pointer-down outside, on `Escape`. (Android back comes in M16, the central Esc routing in M13: mark the local key listener `// TODO(M13): move to command bus`.) A `Sheet` variant slides from the bottom (compact), a `Panel` variant docks to the side (expanded).

**Components and exact content** (order left to right, top to bottom; icons are keys of `tunables.icons`):

| Area | Compact layout | Expanded layout |
|---|---|---|
| Top bar, annotation | `TabSwitcher` (flex, min 44 px; M8 fills it), `openFile`, `ModeSwitch` (3 buttons), `undo`, `redo` | `TabBar` (flex, empty; leading `openFile`), `ModeSwitch`, trailing `overflow` (menu: info) |
| Top bar, organization | same as annotation but `undo`/`redo` hidden | same as annotation |
| Tool area, annotation | one `ToolFab` at the screen edge; tap expands pen, highlighter, eraser (toggled look for the active one) | vertical `ToolStrip` on `T:layout.toolStripSide`: pen, highlighter, eraser, `undo`, `redo` |
| Tool area, organization | one `OrgFab` (opens a sheet with `levelSelector` ×3 steps and `jumpList`) | vertical strip: `levelSelector` (3 icon steps), `jumpList` |
| Bottom bar, annotation | `previous`, `SlideIndicator` ("– / –"; tap opens a slider popup), `next`, `zoomOut`, `zoomIn`, `zoomReset`, `overflow` (menu: `showMore`, `showLess`, `info`) | `previous`, slider with `SlideIndicator`, `next`, `zoomOut`, `zoomIn`, `zoomReset`, `showMore`, `showLess`, `overflow` (menu: `info`) |
| Bottom bar, organization | `previous`, `PageIndicator` ("– / –"), `next`, `zoomOut`, `zoomIn`, `zoomReset`, `overflow` (menu: `info`) | same plus a page slider |
| Presentation | none | none |

- `ModeSwitch`: segmented control with `modeOrganization`, `modeAnnotation`, `modePresentation`; the active mode filled (toggled look), the others outlined. Presentation is disabled while no document is open (it needs one). Pressing sets `UiStore.mode`.
- Tool buttons toggle `UiStore.tool` (tap on the active tool deactivates it); a tool button is disabled without a document (FIL-007). Switching to a mode other than annotation sets `tool` to `null` (ANN-007).
- Everything that needs a document is disabled: undo, redo, tools, previous/next, indicators, slider, zoom buttons, show more/less, level selector, jump list. Always enabled: `openFile` (does nothing yet), `ModeSwitch` (except presentation), `overflow`, `info`.
- `info` opens a small popover showing the version string from `APP_VERSION` (`UIX-015`; text is the version string only).
- The bars are `T:layout.barHeightPx` high. A bar never grows: when the controls of a bar do not fit, the surplus goes to `overflow` (use the table; do not invent wrapping).

**Translation file** gets the keys `a11y.*` and `tooltip.*` for every icon key; no other text in templates (lint enforces it).

## Tests

- Unit: `layout.spec.ts` (from fixtures); `UiStore` (mode switch clears the tool; presentation disabled without document); icon asset test.
- Component tests: `IconButton` toggled/disabled states and `aria-label`; tooltip timing with fake timers (hover 600 ms, long press 500 ms); `ModeSwitch` marks exactly the active mode as toggled; `PopupHost` closes on outside pointer-down and on Escape.
- E2E (Playwright, all three engines, the viewports below): assert via DOM and `boundingBox()`:
  - 360×800, 800×360 and 599×1000: compact. 1280×800 and 2560×1440: expanded. 320×568: compact and no horizontal page scroll (`scrollWidth <= clientWidth`).
  - Bars are 48 px high (±1); every visible control's box is at least 44×44 px.
  - The controls present in each mode/size class match the table (count and `aria-label`s).
  - With no document the disabled set matches the list above; the canvas area's computed background equals `tunables.colors.canvasGrey`.
  - Switching mode via the `ModeSwitch` shows/hides the right controls; presentation shows no bars.

## Do not

- Do not implement file opening, tabs, PDF rendering, drawing, gestures, keyboard navigation, or full screen.
- Do not add UI libraries (no Angular Material, no CSS frameworks). Plain CSS with the custom properties.
- Do not put colors, sizes or key bindings in component code; no visible text except numbers, the version string and file names.
- Do not lock the screen orientation.
