### S1 — `geometry.ts`

- `rectArea`: `width * height`. `rectUnion`: min of left/top, max of right/bottom.
- `pageDisplaySize`: swap width/height for rotate 90 and 270.
- `userToDisplay` / `displayToUser`: formulas in the doc comment; `view = [x0, y0, x1, y1]`.
  Inverse: rotate 0: `(x0 + a, y1 - b)`; 90: `(x0 + b, y0 + a)`; 180: `(x1 - a, y0 + b)`; 270: `(x1 - b, y1 - a)` for display point `(a, b)`.
- `bitmapRectToDisplay`: divide all four fields by `scale`.
- `fitScaleToPixelCap`: `Math.min(desired, Math.sqrt(maxPixels / (w * h)))`.

### S2 — `detection.ts`

`selectSystemRects` in plain steps:

```
valid = rects without width<=0 or height<=0
if valid is empty -> []
drop the first rect with the maximum area            -> rest   (empty -> [])
areas = sorted ascending areas of rest
threshold = 0
if rest.length >= 2:
    bestGap = -1
    for i in 0..areas.length-2:
        gap = areas[i+1] - areas[i]
        if gap >= bestGap: bestGap = gap; bestI = i      // ">=": among equal gaps the later one (larger areas) wins
    if bestGap > 0: threshold = (areas[bestI] + areas[bestI+1]) / 2
keep rect r of rest if
    (area(r) > threshold AND r.width >= minSystemWidthRatio * pageWidth)
    OR  r.width >= fullWidthSystemRatio * pageWidth
return kept sorted by y, then x
```

`gapsOnPage`: sort a copy by y, `max(0, next.y - (prev.y + prev.height))`. `median`: sort a copy; even count → mean of the middle two; empty → `null`. `computePaddings`: pooled median over all pages' gaps; per page own median if the page has at least one gap, else pooled median if it exists, else `fallbackPageHeightRatio * page.height`. `paddedArea`: expand then clamp to `[0,width] × [0,height]`.

### S3 — `junctions.ts`

```
flattenSystems: pages sorted by pageIndex; skip pages with no systems; systems sorted by y then x; index = running count from 1
junctionCount:  flattenSystems(pages).length
computeBars:    n = 0
  for each page with systems, in pageIndex order:
      first = n + 1;  sorted = systems sorted by y, x
      bar(junction first-1, page, y 0, height max(0, sorted[0].y))
      for i in 0..sorted.length-2:
          bottom = sorted[i].y + sorted[i].height
          bar(junction first+i, page, y bottom, height max(0, sorted[i+1].y - bottom))
      n += sorted.length
      bottom = last.y + last.height
      bar(junction n, page, y bottom, height max(0, page.height - bottom))
barsOfJunction: filter by junction, keep order
```

### S4 — `aspect-ratio.ts`

```
stepAspectRatio(current, direction, {min, max, step}):
    q = current / step
    index = direction == 'more' ? ceil(q - 1e-9) - 1 : floor(q + 1e-9) + 1
    value = round10(index * step)           // round10(x) = Math.round(x * 1e10) / 1e10
    return clamp(value, min, max)
initialAspectRatio(w, h, {min, max, roundDecimals}) = clamp(round(w / h to roundDecimals), min, max)
orientationOf(w, h) = w >= h ? 'landscape' : 'portrait'
```
